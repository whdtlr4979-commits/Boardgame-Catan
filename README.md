# 카탄 개척자

PC와 모바일 브라우저에서 즐기는 **카탄** 웹 보드게임입니다.
컴퓨터·한 기기 여러 명·온라인 친구와 함께 플레이할 수 있고, 빌드 과정 없이 동작합니다.

## 실행 방법

Node.js 18 이상이 필요합니다.

```bash
npm install          # Postgres 연결용 pg 패키지 설치
npm start            # 게임 서버 실행 → http://localhost:8080
```

서버가 게임 화면과 온라인 대전 기능을 함께 제공합니다.
같은 와이파이의 휴대폰에서는 `http://<PC의 IP>:8080` 으로 접속하세요.

온라인 기능 없이 혼자/한 기기로만 할 때는 정적 파일만으로도 됩니다 (`npm run static`, GitHub Pages 등).

## 온라인 대전

1. 시작 화면의 **온라인 대전**에서 이름을 적고 **방 만들기**를 누릅니다.
2. 대기실에 나오는 **방 코드(4글자)** 나 **초대 링크**를 친구에게 보냅니다.
3. 친구는 링크를 열거나 코드를 입력해 참가합니다. 빈자리는 **컴퓨터 추가**로 채울 수 있습니다.
4. 3~4명이 되면 방장이 **게임 시작**을 누릅니다.

- 게임 판정은 서버가 하며, 각자 자기 손패와 발전 카드만 볼 수 있습니다.
- 7이 나오면 카드를 버리는 사람들이 동시에 버립니다.
- 플레이어 교역은 제안 → 상대가 수락/거절 → 제안자가 수락한 사람 중 한 명과 교역합니다.
- 새로고침하거나 연결이 끊겨도 같은 기기에서 다시 열면 자동으로 이어서 합니다.
- 오래 접속이 끊긴 사람이 있으면 방장이 메뉴에서 그 자리를 컴퓨터로 대체할 수 있습니다.
- 방 상태를 데이터베이스에 저장하면 서버가 재시작되거나 잠들었다 깨어나도 게임이 이어집니다 (아래 참고).

### 방 상태 저장

서버는 방이 바뀔 때마다 상태(보드, 손패, 차례, 참가자)를 저장소에 저장합니다.
서버가 다시 켜지면 누군가 그 방에 접속할 때 저장소에서 불러오고, 접속해 있던 사람들은 자동으로 다시 연결됩니다.
저장소는 환경 변수로 고릅니다.

| 환경 변수 | 저장 위치 | 언제 쓰나요 |
| --- | --- | --- |
| `DATABASE_URL` | Postgres 데이터베이스 | Render 같은 클라우드 (디스크가 유지되지 않는 곳) |
| `ROOMS_DIR` | 폴더 안의 JSON 파일 | 내 PC나 디스크가 유지되는 서버 |
| (없음) | 메모리 | 테스트용. 서버를 재시작하면 방이 사라집니다 |

- 테이블(`catan_rooms`)은 서버가 처음 켜질 때 자동으로 만듭니다.
- 7일 동안 바뀌지 않은 방은 자동으로 지웁니다.
- 자체 서명 인증서를 쓰는 데이터베이스라면 `DATABASE_SSL=no-verify`를 함께 설정하세요.

```bash
ROOMS_DIR=./rooms npm start                                    # 파일로 저장
DATABASE_URL=postgres://user:pass@host:5432/db npm start       # Postgres로 저장
```

### 인터넷에 공개하기 (예: Render 무료 플랜 + Supabase)

Render 무료 플랜은 15분 동안 접속이 없으면 서버가 잠들고, 잠들거나 재배포할 때 디스크 내용도 사라집니다.
그래서 **Render에서는 Postgres 데이터베이스를 연결해야** 방이 유지됩니다.

1. **데이터베이스 만들기**: [Supabase](https://supabase.com)에서 새 프로젝트를 만듭니다 (리전: Seoul).
   - Data API와 "Automatically expose new tables"는 끄고, "Enable automatic RLS"는 켭니다. 이 게임은 연결 주소로 직접 접속하므로 Data API가 필요 없습니다.
   - 프로젝트의 **Connect** → **Session pooler** 연결 주소를 복사하고 `[YOUR-PASSWORD]`를 실제 비밀번호로 바꿉니다.
     (Direct connection은 IPv6 전용이라 Render에서 접속되지 않을 수 있습니다.)
   - [Neon](https://neon.tech)도 됩니다. Render의 무료 Postgres는 30일 뒤 만료되므로 권장하지 않습니다.
2. **서버 배포**: [render.com](https://render.com)에서 **New → Blueprint**를 고르고 이 저장소를 연결합니다.
   `render.yaml`에 리전(Singapore), 브랜치(`main`), 빌드·실행 명령, `DATABASE_SSL=no-verify`가 들어 있어서
   **`DATABASE_URL`만 입력**하면 됩니다. 연결 주소 끝에 `?sslmode=require`는 붙이지 마세요.
3. **확인**: 서버 로그에 `방 저장소: postgres`가 보이면 연결된 것입니다. `https://<서비스 주소>/api/health`의 `storage` 값으로도 확인할 수 있습니다.

`main`에 머지할 때마다 자동으로 다시 배포됩니다.

Railway, Fly.io 등 Node.js를 실행할 수 있는 곳이면 어디든 `npm start`로 동작합니다 (`PORT` 환경 변수 사용).

GitHub Pages에서 화면을 열고 서버는 따로 두고 싶다면 `js/config.js`의 `SERVER_URL`에 서버 주소를 적으세요.

## 게임 기능

- **카탄 기본판 규칙** (3~4인)
  - 무작위 보드 (지형 19개, 숫자 토큰, 6·8 비인접 배치, 항구 9개)
  - 스네이크 순서 초기 배치, 두 번째 개척지 초기 자원
  - 주사위 생산 (도시 2배, 도둑 칸 제외, 은행 자원 부족 규칙)
  - 7: 8장 이상 카드 절반 버리기 → 도둑 이동 → 카드 1장 강탈
  - 건설: 도로 / 개척지 (거리 규칙) / 도시 / 발전 카드
  - 발전 카드 25장: 기사 14, 승리 점수 5, 도로 건설 2, 풍년 2, 독점 2
    (한 차례 1장, 산 차례 사용 불가, 주사위 전 사용 가능)
  - 해상 교역 4:1, 범용 항구 3:1, 자원 항구 2:1
  - 플레이어 간 교역 (컴퓨터는 이득을 따져 수락/거절)
  - 최장 교역로(5+), 최강 기사단(기사 3+), 10점 승리
- **온라인 대전**: 방 코드/초대 링크로 친구와 각자의 PC·휴대폰에서 플레이
- **컴퓨터 플레이어(AI)**: 자리마다 사람/컴퓨터 선택, 속도 조절 가능
- **핫시트 모드**: 여러 사람이 한 기기로 플레이할 때 차례마다 화면 가림막
- **자동 저장**: 새로고침해도 `이어하기`로 계속
- **진행 상황 화면**
  - 차례 배너: 누구 차례인지와 지금 단계(주사위·건설·교역·도둑·카드 버리기 등)
  - 플레이어 카드: 점수 진행 막대, 자원 카드 수(8장 이상이면 경고), 발전 카드, 기사, 도로 길이, 최장 교역로·최강 기사단 표시
  - 주사위로 받은 자원이 각 플레이어 카드에 잠깐 떠오릅니다.
  - 방금 일어난 일은 한 줄로만 잠깐 보여 줍니다. 지난 기록은 남기지 않아서, 실제 보드게임처럼 누가 무엇을 가졌는지는 직접 기억해야 합니다. (온라인에서도 서버가 최근 한 건만 보냅니다.)
- **주사위 연출**: 모두의 마블처럼 보드를 비스듬히 내려다보는 시점에서, 실제 카탄처럼 모서리가 둥근 노란 주사위(빨간 눈)와 빨간 주사위(노란 눈)를 던집니다. 통통 튀며 앞으로 구르다 결과 눈이 **윗면**에 오도록 멈추고, 착지 순간 화면이 흔들리며 금빛 합계가 튀어나온 뒤 위쪽 주사위 자리로 날아갑니다. 주사위는 WebGL로 픽셀마다 빛을 계산해 표면이 매끈하게 반짝이며, WebGL을 못 쓰는 기기에서는 평면 주사위로 보여 줍니다.
- **반응형 UI**: PC는 왼쪽에 큰 보드, 오른쪽 두 열에 플레이어 상태·남은 말 / 행동 버튼·손패를 놓아 스크롤 없이 한 화면에 보입니다. 휴대폰 가로는 왼쪽 보드·오른쪽 정보, 휴대폰 세로는 위아래 배치
  - 모바일은 한 번 탭으로 선택, 한 번 더 탭(또는 [확정])으로 건설해 실수를 막습니다.

## 그림 스타일

요즘 보드게임처럼 일러스트 느낌으로 그립니다. 그림 파일 없이 모두 캔버스 벡터로 그려서 어떤 화면 크기에서도 선명합니다.

- **바다 틀**: 실제 카탄처럼 위아래가 평평한 큰 육각형 바다 틀, 섬 둘레의 얕은 물, 나무 잔교가 달린 항구 토큰
- **지형 타일**: 두께감 있는 타일 사이로 가는 틈이 보이고, 빽빽한 침엽수 숲, 언덕과 울타리가 있는 목초지, 밭고랑과 농가가 있는 밀밭, 가마가 있는 계단식 점토 채굴장, 광산이 있는 바위산, 사구와 선인장 사막
- **숫자 토큰**: 두꺼운 종이 토큰 모양, 6·8은 빨간 숫자
- **말**: 카탄 특별판의 조각 플라스틱 말처럼 — 언덕 위 집 두 채의 마을(개척지), 교회와 집들이 모인 도시, 울퉁불퉁한 둑 모양 도로, 모자 쓴 도적 세 명의 도둑. WebGL로 한 번 입체로 그려 그림으로 만들어 두고 보드에 붙이며, WebGL을 못 쓰는 기기에서는 2D 나무 말 그림을 씁니다
- **화면**: 나무 테이블 위에 종이 카드처럼 보이는 패널, 자원 카드는 실제 카드 모양
- **플레이어 상태**: 자원 카드·발전 카드·사용한 기사·가장 긴 도로를 큰 숫자 칸으로 보여 주고, 최강 기사단·최장 교역로는 금색 칸과 +2 배지, 자원 8장 이상은 빨간 칸
- **남은 말**: 손패 아래 상자에 남은 개척지·도시·도로를 실제 말 그림으로 늘어놓고, 이미 놓은 말은 흐리게 표시

글꼴은 Google Fonts의 [Jua](https://fonts.google.com/specimen/Jua)(제목·버튼)와 [Noto Sans KR](https://fonts.google.com/noto/specimen/Noto+Sans+KR)(본문)를 씁니다.
그림은 `js/art.js`(장식·말·아이콘), `js/terrain.js`(지형 타일), `js/pieces3d.js`(조각 말), `js/render.js`(바다 틀·항구·보드 배치)에 있습니다.

## 구조

| 파일 | 내용 |
| --- | --- |
| `js/constants.js` | 자원, 비용, 카드 구성 등 규칙 상수 |
| `js/board.js` | 헥스·꼭짓점·변 위상, 무작위 보드 생성 |
| `js/game.js` | 규칙 엔진 (직렬화 가능한 상태 + 행동 검증/적용) |
| `js/ai.js` | 컴퓨터 플레이어 휴리스틱 |
| `js/art.js` | 지형 장식, 말, 아이콘 그림 (벡터) |
| `js/terrain.js` | 지형 타일 그림 (바탕 질감과 지형별 장식) |
| `js/pieces3d.js` | 조각 말 (WebGL로 입체를 그려 그림으로 저장) |
| `js/render.js` | 보드 렌더러 (고해상도 캔버스), 터치/클릭 판정 |
| `js/main.js` | 화면 흐름, 대화상자, 저장, 온라인 화면 |
| `js/dice.js` | 주사위 굴림 연출 |
| `js/net.js` | 온라인 서버 통신 (fetch + Server-Sent Events) |
| `server/server.js` | 정적 파일 + 방 API 서버 |
| `server/rooms.js` | 방·대기실, 서버 판정, 교역 제안, 비밀 정보 가리기, 방 저장/복원 |
| `server/store.js` | 방 저장소 (Postgres / 파일) |
| `tests/` | 엔진·AI 테스트, 서버(방 흐름·권한·비밀 정보·HTTP/SSE) 테스트, 저장/복원 테스트 |

## 테스트

```bash
npm test
# Postgres 저장소 테스트까지 돌리려면 빈 테스트 데이터베이스 주소를 지정합니다
TEST_DATABASE_URL=postgres://postgres@localhost:5432/catan_test npm test
```

GitHub Actions(`.github/workflows/ci.yml`)는 PR마다 Postgres를 띄워 전체 테스트를 실행합니다.

## GitHub Pages 배포

`main` 브랜치에 푸시하면 `.github/workflows/pages.yml`이 사이트를 배포합니다.
저장소 **Settings → Pages → Source**를 **GitHub Actions**로 한 번 설정해 주세요.
