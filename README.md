# 픽셀 카탄 (Pixel Catan)

PC와 모바일 브라우저에서 즐기는 **도트 아트 스타일 카탄** 웹 게임입니다.
설치나 빌드 없이 정적 파일(HTML/CSS/JS)만으로 동작합니다.

## 실행 방법

ES 모듈을 사용하므로 `file://`로 직접 열지 말고 간단한 웹 서버로 실행하세요.

```bash
npm start            # http://localhost:8080
# 또는
python3 -m http.server 8080
```

같은 와이파이의 휴대폰에서 `http://<PC의 IP>:8080` 으로 접속하면 모바일로도 플레이할 수 있습니다.
GitHub Pages에 올리면 어디서나 접속할 수 있습니다 (아래 참고).

## 게임 기능

- **카탄 기본판 규칙** (3~4인)
  - 무작위 보드 (지형 19개, 숫자 토큰, 6·8 비인접 배치, 항구 9개)
  - 스네이크 순서 초기 배치, 두 번째 개척지 초기 자원
  - 주사위 생산 (도시 2배, 도둑 칸 제외, 은행 자원 부족 규칙)
  - 7: 8장 이상 카드 절반 버리기 → 도둑 이동 → 카드 1장 강탈
  - 건설: 도로 / 개척지 (거리 규칙) / 도시 / 발전 카드
  - 발전 카드 25장: 기사 14, 승리 점수 5, 도로 건설 2, 풍년 2, 독점 2
    (한 차례 1장, 산 차례 사용 불가, 주사위 전 사용 가능)
  - 해상 교역 4:1, 범용 항구 3:1, 자원 항구 2:1
  - 플레이어 간 교역 (컴퓨터는 이득을 따져 수락/거절)
  - 최장 교역로(5+), 최강 기사단(기사 3+), 10점 승리
- **컴퓨터 플레이어(AI)**: 자리마다 사람/컴퓨터 선택, 속도 조절 가능
- **핫시트 모드**: 여러 사람이 한 기기로 플레이할 때 차례마다 화면 가림막
- **자동 저장**: 새로고침해도 `이어하기`로 계속
- **반응형 UI**: 데스크톱은 보드 + 사이드 패널, 모바일은 세로 배치
  - 모바일은 한 번 탭으로 선택, 한 번 더 탭(또는 [확정])으로 건설해 실수를 막습니다.

## 도트 아트

보드는 304×292 픽셀의 저해상도 캔버스에 직접 픽셀을 찍어 그린 뒤
`image-rendering: pixelated`로 확대합니다. 지형 장식, 말, 아이콘은 모두
`js/sprites.js`의 문자열 픽셀 맵으로 정의되어 있어 쉽게 수정할 수 있습니다.
글꼴은 한글 도트 폰트 [갈무리(Galmuri)](https://github.com/quiple/galmuri) (SIL OFL 1.1)를 사용합니다.

## 구조

| 파일 | 내용 |
| --- | --- |
| `js/constants.js` | 자원, 비용, 카드 구성 등 규칙 상수 |
| `js/board.js` | 헥스·꼭짓점·변 위상, 무작위 보드 생성 |
| `js/game.js` | 규칙 엔진 (직렬화 가능한 상태 + 행동 검증/적용) |
| `js/ai.js` | 컴퓨터 플레이어 휴리스틱 |
| `js/sprites.js` | 도트 스프라이트, 숫자 픽셀 글꼴 |
| `js/render.js` | 캔버스 렌더러, 터치/클릭 판정 |
| `js/main.js` | 화면 흐름, 대화상자, 저장 |
| `tests/` | 엔진 단위 테스트 + AI 끝까지 대전 테스트 |

## 테스트

```bash
npm test
```

## GitHub Pages 배포

`main` 브랜치에 푸시하면 `.github/workflows/pages.yml`이 사이트를 배포합니다.
저장소 **Settings → Pages → Source**를 **GitHub Actions**로 한 번 설정해 주세요.
